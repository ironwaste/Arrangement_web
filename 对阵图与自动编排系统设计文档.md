# 对阵图生成与自动编排系统技术文档

## 一、系统概述

本系统用于跆拳道、摔跤、拳击等比赛的对阵编排管理，核心功能包括：
- 自动签位分配（Draw Number Assignment）
- 对阵图生成（Bracket Generation）
- 对阵表编排（Match Scheduling）
- 场地单元分配（Venue & Unit Allocation）

## 三、签位分配逻辑

### 3.1 标准签位顺序生成算法

**文件位置**: [routes/autoScheduler.js:1-16](file:///d:/vscode/arragment/Arrangement_web/routes/autoScheduler.js#L1-L16)

**算法原理**: 采用"镜像对称"算法生成锦标赛签位表，确保种子选手在后半区相遇。

```javascript
function generateStandardSeedOrder(size) {
  // 2人: [1, 2]
  // 4人: [1, 4, 2, 3]
  // 8人: [1, 8, 5, 4, 2, 7, 6, 3]
  // 16人: [1, 16, 9, 8, 5, 12, 13, 4, 2, 15, 10, 7, 6, 11, 14, 3]
}
```

**数学原理**:
1. 从最小对阵数开始（如2人）
2. 每次翻倍时，将已有序列按特定规则展开
3. 新序列遵循"首尾镜像"原则，确保强手不会过早相遇

**核心思想**: 同队运动员应尽量晚相遇（最大距离原则）


```javascript
// 参数
{
  event_id: 赛事ID（必填）,

  category_order: 比赛顺序

// 响应
{
  success: true,
  data: {
    generated: 10,      // 成功生成的级别数
    skipped: 2,         // 跳过的级别数
    errors: ["级别: 运动员不足2人，跳过"],
    results: ["女子46kg: 7人，对阵已生成"]
  }
}
```

## 九、核心算法总结

### 9.1 签位分配算法特点

- **标准签位顺序**: 使用镜像对称算法，确保种子选手在决赛前不会相遇
- **同队回避**: 通过计算同队选手间的最小距离，尽量将同队选手分散
- **随机性**: 非种子选手使用Fisher-Yates洗牌算法引入随机性
- **种子保护**: 已分配签位的种子选手保持原有位置

### 9.2 循环赛编排算法特点

- **轮转编排**: 固定一个位置，其余位置顺时针轮转
- **公平性**: 确保每队运动员比赛场次相同
- **分站循环**: 将运动员分为上区/下区，减少比赛场次

### 9.3 对阵图生成算法特点

- **多模式支持**: 支持单败淘汰、循环赛、分站循环赛、双败淘汰赛、分区循环赛等多种赛制
- **数据完整性**: 自动处理轮空（Bye）情况
- **结构化存储**: 使用bracket_manager库管理对阵数据，支持复杂查询
