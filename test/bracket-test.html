🏆 Bracket Manager & Viewer 测试

使用 bracket-manager 创建对阵图，使用 bracket-viewer 显示分区循环赛、单败淘汰赛和双败淘汰赛

🎯 分区循环赛（Pool Stage）

代码示例：
await manager.create.stage({
  tournamentId: 999,
  name: 'Groups',
  type: 'round_robin',
  seeding: [
    'Alpha',
    'Bravo',
    'Charlie',
    'Delta',
    'Echo',
    'Foxtrot',
    'Golf',
    'Hotel'
  ],
  settings: {
    groupCount: 2,
    seedOrdering: ['groups.effort_balanced']
  }
});

🏁 单败淘汰赛（Single Elimination）

赛制说明：

8名选手进行单败淘汰赛，最终产生1名冠军

对阵图结构：1/4决赛（4场）→ 半决赛（2场）→ 决赛（1场）

🔄 双败淘汰赛（Double Elimination）

赛制说明：

4支队伍进行双败淘汰赛，失败两次被淘汰

最终产生1名冠军和1名亚军
